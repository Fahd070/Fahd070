## About me

I'm a third-year university student. My interest in programming started well before university: I taught myself by reading, experimenting and building things, and most of what I know came from shipping projects rather than finishing tutorials.

That habit still shapes how I work. I like taking an idea from a blank folder to something people can actually use, and I treat every project as a chance to learn a tool or technique properly.

Alongside my studies I run **Fahd Ybrmj** (فهد يبرمج), an educational channel where I teach programming and technology. Explaining a concept clearly forces me to understand it better, and helping others start their own path is the part of this work I value most.

## Featured projects

### [Pure Home Showcase](https://github.com/Fahd070/pure-home-showcase)

A public, interactive showcase of Pure Home, a workforce and service management platform. It covers customer profiles that compare previous and next service, a drag-and-drop scheduling board, technician checklists, and reports with CSV export, all in Arabic and English with full RTL/LTR layouts. It runs entirely in the browser on generated demo data and is covered by unit and end-to-end tests.

`React` `TypeScript` `Vite` `Tailwind CSS` `Vitest` `Playwright`

[Live demo](https://pure-home-showcase.vercel.app) · [Repository](https://github.com/Fahd070/pure-home-showcase)

### [Golden Pizza](https://github.com/Fahd070/Golden-Pizza)

A bilingual (English/Arabic) pizza ordering website with an interactive menu, an order page for size, crust and extras, a live price calculator, instant search and RTL support. It is built with plain HTML, CSS and JavaScript and has no dependencies.

`HTML` `CSS` `JavaScript`

[Live site](https://fahd070.github.io/Golden-Pizza/html/mainPage.html) · [Repository](https://github.com/Fahd070/Golden-Pizza)

### [Weber](https://github.com/Fahd070/weber)

A website for a web design and development studio, currently in progress. It uses the Next.js App Router and is backed by a documented design system and component library.

`Next.js` `React` `TypeScript` `Tailwind CSS`

[Repository](https://github.com/Fahd070/weber)
